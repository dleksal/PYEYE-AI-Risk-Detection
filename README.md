# PYEYE AI Risk Detection System

Real-time AI risk detection system using face recognition and emotion analysis.

---

## Overview

PYEYE is an AI-based monitoring system that detects faces in real time and analyzes emotional states to estimate potential risk levels.

The system was developed as a capstone project using Python, OpenCV, MediaPipe, and Streamlit.

---

## Features

- Real-time face recognition
- Emotion analysis
- Risk score visualization
- Streamlit dashboard
- CSV event logging
- Webcam-based monitoring

---

## Tech Stack

- Python
- OpenCV
- MediaPipe
- Streamlit
- Pandas
- Seaborn

---

## Project Goal

Traditional CCTV systems mainly record incidents after they happen.

PYEYE aims to provide proactive monitoring by analyzing emotional signals and detecting potentially risky situations in real time.
